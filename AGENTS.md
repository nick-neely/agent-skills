# AGENTS.md

Keep every skill portable and safe for a public repository.

- Read the complete `SKILL.md` before changing a skill.
- Keep referenced scripts and documentation inside that skill directory.
- Do not add secrets, customer data, private project context, or machine-local
  absolute paths.
- Validate the full repository before proposing publication.
- Do not edit installed copies under an agent runtime directory; edit source
  here and reinstall through the skills CLI.
